# Glossary

| Term | Definition |
|---|---|
| ETL | Extract, Transform, Load |
| ELT | Extract, Load, Transform |
| Data Warehouse | Central repository for integrated enterprise data |
| Metadata | Data describing the characteristics of other data |
| Snowflake | Cloud-native data platform used for analytics and data warehousing |
| dbt | Data Build Tool used for SQL-based data transformation |
| LLM | Large Language Model |
| Generative AI | AI capable of generating text, code, and other content |
| Cloud-Native | Applications and architectures designed specifically for cloud environments |
| Technical Debt | Long-term maintenance burden caused by earlier design or implementation decisions |
| Data Governance | Policies and processes ensuring data quality, security, and compliance |
| Proof of Concept (PoC) | A limited implementation demonstrating the feasibility of an idea |
